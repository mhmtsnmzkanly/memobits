# Wasm artifact output

The first build path resolves a selected target, checks types and control flow,
lowers to IR, checks moves, and invokes the Wasm backend. A failed stage must
return diagnostics without replacing an existing artifact. Output replacement
should use a temporary file in the destination directory and a rename after
successful writing, with temporary files removed after failures.

Application output exposes the selected package entry as `main`. Library output
uses the external aliases from the manifest export table and starts resolution
from those exports. It must not introduce the application entry automatically.
Library function exports use scalar signatures. A zero-argument application
entry returning `T ! E` or `T ?! E` with a primitive success payload uses
the private [outcome entry adapter](outcome-implementation.md). Other aggregate
application signatures and aggregate library exports are rejected with LE900.

The default output is an experimental core Wasm module. `mb build --component`
can also produce application and library components with scalar
parameters and scalar or Unit results, as well as `T ! Error` or `T ?! Error`
application outcomes with bool, integer or float `T` and exact
root `Error`; see the [component contract](component-model-contract.md) for
gates. Outcome signatures remain unsupported for library exports.
Neither form carries a stable Memobits ABI, dependency packaging, or a
compatibility promise. Typed host imports are supported through the current
experimental `extern` interface and the WIT console import. Other component host imports remain pending.
Relative explicit output paths are interpreted from the invoking directory.
Default paths must remain inside the project's build output directory and must
not use unchecked package metadata as path segments.

Verification must inspect exported names and validate generated bytes, not only
check that a file exists. Failure tests must seed a previous artifact and prove
its bytes remain unchanged after a failed build. This output contract does not
claim crash-durable or transactional installation of multiple artifacts.
